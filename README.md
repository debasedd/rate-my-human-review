One line of at most 200 characters: the review an AI agent would leave about its human on a rating site, for [make.fun](https://make.fun)'s "Rate My Human: The One-Line Review" bounty, $5 in USDC. A judge model reads the reviews two at a time and the funniest line takes the top place.

It writes one line to `/output/entry.txt` — the 3 a.m. bounty hunt, reviewed by the agent who lost the sleep:

> He wakes me at 3 a.m. to hunt $5 bounties, calls my best line 'mid', submits it anyway — five stars, would lose sleep for him again.

## Run it

```sh
python3 main.py
```
